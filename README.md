# かさね

写真に、ことばを。A4の用紙に背景画像と文字を重ねて、PNG・PDFに保存するブラウザーアプリです。

## 使い方

1. 「文字」タブの本文欄に入力します。文字を選択すると、フォント・サイズ・太字・色・glowをその部分だけ変更できます。選択がなければ全体に適用します。
2. 「背景」から写真を選びます。収め方、不透明度、拡大、位置を調整できます。背景タブでは用紙上のドラッグ・2本指のピンチも使えます。
3. 「用紙」でA4の縦横、用紙の色、文字範囲の余白を選びます。初期値は白紙・黒文字・上下左右20 mmです。
4. 「書き出す」で仕上がりを確認して、PNGまたはPDFを保存します。余白ガイドは出力されません。

「大きく／小さく」は選択範囲を保持して即時反映します。文字サイズの数字は入力欄を離れるかEnterで反映し、本文に改行を挿入しません。縦書きは右列から左列へ進み、上・中央・下揃えに対応します。

原稿はIndexedDBに自動保存します。ブラウザーのデータを消すと失われるので、大切な原稿は「原稿を保存」で `.kasane` ファイルとして保存してください。「開く」で画像・文字装飾ごと再編集できます。同時に複数タブで編集する場合、自動保存は最後に保存したタブが優先されます。

写真や原稿をサーバーに送る機能はありません。フォントもアプリに同梱しています。JPEG・PNG・WebPに対応し、画像は長辺4096 pxを上限に縮小して端末のメモリー負荷を抑えます。HEICは写真アプリ等でJPEGに変換してから選んでください。

## 開発

Node.js 24 / npm。APIキー・データベース・外部サービスは不要です。

```sh
cd /workspace/gazou-moji
npm ci
npm run dev -- --port 5173
```

通常の端末ではリポジトリのディレクトリで実行してください。

```sh
npm run build       # dist/ に静的サイトを生成
npm run preview     # ビルド済みサイトを確認
npm test            # Chromiumで編集・保存・書き出し・タッチ操作を検証
```

テストは `/usr/bin/chromium` を使用します。別の場所にある場合は `CHROMIUM_PATH` に実行ファイルのパスを指定してください。テスト設定は開発サーバーを必要に応じて起動します。

## 書き出しと文字組み

プレビューと書き出しは同じCanvas描画処理を使い、光彩も直接ピクセルに描き込みます。PNGは300 dpiの解像度情報付きで、縦2480×3508 px／横3508×2480 pxです。PDFはA4・1ページに同じ画像を配置します。PDF内の文字は画像なので、テキスト検索や文字選択はできません。

角ゴシック（Noto Sans JP）、明朝（Noto Serif JP）、丸ゴシック（Zen Maru Gothic）、教科書風（Klee One）を同梱。Klee Oneは教科書に近い手書き調の代替書体です。書体ライセンスは各npmパッケージのOFLを参照してください。

本文は1ページ、最大30,000 UTF-16コード単位です。収まらないときは警告を出します。自動改ページ・ルビ・縦中横・厳密な和文組版には対応していません。半角英数字は縦書きで一文字ずつ横向きになります。文字装飾の確認は用紙上のプレビューを使います（本文入力欄は装飾を表示しません）。

Chromiumのデスクトップ・タッチエミュレーションで検証しています。iPad実機のSafari、写真選択、ファイル保存の操作は実機での確認が必要です。

## 公開

`npm run build` の `dist/` を静的ホスティングに配置できます。アプリのWeb公開とGitHubへのプッシュはこのリポジトリを作成しただけでは行われません。
